# Office Action Response Workflow

1. Read the Office Action in full and list every rejection and objection.
2. Review the application as filed for amendment support.
3. Review each cited reference against the rejected claims.
4. Check client prosecution guidelines (get_client) before proposing amendments.
5. Propose a response strategy and report to the client within the client's reporting deadline.

- [ ] Docket and calendar verified against firm docketing system
- [ ] Rejections and objections listed
- [ ] References reviewed
- [ ] Amendment support identified
- [ ] Strategy approved by client
- [ ] Response drafted and reviewed
